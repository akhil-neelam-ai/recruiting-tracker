# prompts/reminders.md

Key prompt for reminders.

## Prompt

`feature/reminders`: create reminders with a due date and mark them done, using the existing reminders table. Open an issue that pastes the user story verbatim from PLAN.md: "[My feature 2] As a user, I want to add a reminder with a due date on a person, mark it done, and see what's due this week, so that no follow-up slips." Fetch the latest main before branching. Save the key prompts in prompts/reminders.md. Open a PR into main with "closes #<n>". Do not merge, do not deploy, and do not touch PLAN.md or PR #10.

This branch does not include the people UI. The reminder form reads people the signed-in user already has.
